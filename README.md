# Freelancer Taskboard

A standalone taskboard for freelancers to plan client work, track time, manage assets, export/import board data, and prepare simple invoices.

## Use locally

Open `index.html` in a browser. The board saves to the browser's localStorage.

## Customization

- Click the studio name, project title, subtitle, client name, or status in the header to edit them.
- Use the starter cards as guidance, then edit or delete them.
- Add columns and cards for your own workflow.
- Change the default hourly rate and currency in the earnings panel, or override the rate per card.
- Use Export Board JSON to keep backups or move a board between browsers.

## Publishing

Deployment files are intentionally not included in this public copy. Choose the publishing target later and add only the deployment files needed for that target.
